# Passenger interface refresh

Use solid, theme-aware surfaces across the project. The home page prioritizes city, travel date and booking search, with the bus image beside the introduction and a short list of route shortcuts below. The shared header puts search, bookings and help first and keeps demo sign-in available. Preserve existing routes and API filter values. The form supports typed cities, direction swapping, date, coach type and departure window. All styling is external CSS and both themes support keyboard focus and narrow-screen layouts.
